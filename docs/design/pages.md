# Continuum-Care-Network 页面结构与信息架构

- 版本：v0.1
- 配套文档：`design-system.md`（设计 token）、`components.md`（页面级组件）
- 技术基座：Next.js App Router，路由按角色分组 `(auth)` / `(patient)` / `(therapist)` / `(admin)`

> 路由守卫规则：`middleware.ts` 校验 access token 与角色；未登录访问受保护路由 → 跳 `/login`；角色不匹配 → 跳 `/403` 或对应角色首页。

---

## 1. 站点地图（Sitemap）


## 2. 全局布局（Layout）

### 2.1 认证布局（(auth)）

- 居中卡片布局：左半品牌区（桌面端）/ 顶部品牌（移动端），右半表单区。
- 卡片：宽 440px（`max-w-[440px]`），`rounded-lg shadow-lg bg-white p-8`。
- 元素顺序：Logo → 页面标题（text-2xl font-semibold）→ 副标题（text-sm neutral-500）→ 表单 → 底部跳转链接。
- 移动端：卡片全宽，左右 padding 16px，无品牌大图。

### 2.2 患者/康复师端布局（应用布局）

- 桌面端（≥1024px）：
  - 左侧 Sidebar 240px（导航）+ 右侧主内容区。
  - 顶部 Topbar 64px：品牌（小）/ 页面标题 / 右侧通知铃铛 + 用户头像菜单。
- 移动端（<1024px）：
  - 顶部 Topbar 56px：汉堡菜单（打开抽屉导航）+ 页面标题 + 通知。
  - 底部 TabBar 56px：首页 / 数据（患者）或 患者（康复师）/ 消息 / 我的。
  - 主内容区底部预留 72px 防止内容被 TabBar 遮挡。

### 2.3 管理端布局

- 桌面端优先：左侧 Sidebar 240px（管理导航）+ Topbar + 内容区。
- 内容区宽度 `max-w-[1200px] mx-auto`，卡片间距 24px。
- 不提供移动端完整导航（管理操作以桌面为主），移动端仅保证可读与横向滚动表格。

## 3. 认证与引导

### 3.1 登录页 `/login`

| 区块 | 内容 |
| --- | --- |
| 品牌区 | Logo、标语「出院不离线，康复不中断」、装饰图形 |
| 表单区 | 账号（手机号/邮箱）、密码、登录按钮（lg 全宽） |
| 辅助 | 忘记密码链接（跳 /forgot-password 占位）、注册引导「还没有账号？立即注册」 |
| 错误 | 表单顶部 Alert（danger）：账号或密码错误 |

### 3.2 注册页 `/register`

| 区块 | 内容 |
| --- | --- |
| 步骤 1：账号信息 | 手机号/邮箱、密码、确认密码（密码强度提示条） |
| 步骤 2：角色选择 | 两张角色卡片（患者 / 康复师），选中态 primary 边框 + 说明文字 |
| 提交 | 注册成功 → 按角色跳转 /onboarding/patient 或 /onboarding/therapist |

角色卡片内容：
- 患者：「出院后在家康复，需要持续健康监测与专业指导」。
- 康复师：「专业康复治疗师，为在册患者制定康复计划与远程指导」。

### 3.3 档案完善 `/onboarding/patient`

| 区块 | 内容 |
| --- | --- |
| 基本信息 | 姓名、性别（单选框组）、出生日期（日期选择）、联系电话（预填注册号） |
| 健康档案 | 既往病史（多行文本）、过敏史（多行文本）、出院小结上传（可选，文件卡片） |
| 紧急联系人 | 姓名、关系、电话（敏感字段，仅患者本人可见） |
| 提交 | 保存成功 → 跳转 /patient（若尚未绑定康复师，显示「待匹配」引导卡片） |

### 3.4 资质提交 `/onboarding/therapist`

| 区块 | 内容 |
| --- | --- |
| 执业信息 | 姓名、执业机构、执业类别（下拉）、资格证书编号 |
| 材料上传 | 资质证明材料（必传，支持多文件，图片/PDF） |
| 专业信息 | 擅长方向（多选 chips）、简介（多行文本，限 200 字） |
| 提交 | 提交成功 → 显示「资质审核中」状态页（warning 徽标），可跳转 /therapist 工作台（只读态） |

## 4. 患者端页面

### 4.1 首页仪表盘 `/patient`

**目标**：一屏掌握今日健康状态、待办、告警与康复师。

| 区块 | 内容 |
| --- | --- |
| 欢迎横幅 | 渐变卡片（primary-50→白）：问候语「早上好，王阿姨」、日期、快捷上报按钮（primary 大按钮「上报今日数据」） |
| 今日健康概览 | 4 个指标卡（血压/心率/体温/血氧）：指标名 + 最新值大数字 + 单位 + 状态点（正常/关注/紧急）+ 迷你趋势箭头 |
| 待办事项 | 今日康复计划任务列表（未打卡任务，卡片式，右侧打卡按钮） |
| 告警提醒 | 若存在未处理告警：顶部 warning/danger Alert 卡片「您的血压偏高，请留意」+ 查看详情 |
| 我的康复师 | 康复师卡片（头像、姓名、资质标签、擅长方向）+ 「联系康复师」按钮；未绑定时显示「待匹配」引导卡 |
| 最近消息 | 最新一条消息预览 + 未读红点，点击跳 /patient/messages |

### 4.2 健康数据上报 `/patient/health`

| 区块 | 内容 |
| --- | --- |
| 上报表单卡 | 四个指标输入（血压含收缩压+舒张压两个输入框；心率/体温/血氧各一），带单位后缀与校验提示；提交按钮 |
| 今日已上报 | 若今日已上报，显示已上报摘要卡 + 「再次上报」入口（每次上报独立记录） |
| 历史记录 | 列表（时间倒序，分页）显示各指标值 + 状态徽标 |
| 趋势图表 | Tab 切换指标（血压/心率/体温/血氧），折线图展示近 7/30 天趋势，标注参考区间与越界点 |

交互：提交成功 → Toast「上报成功」+ 若触发异常指标告警，弹窗/横幅展示告警详情（danger/warning 按级别）。

### 4.3 我的康复师 `/patient/therapist`

| 区块 | 内容 |
| --- | --- |
| 绑定状态 | 顶部状态卡：已绑定（active 徽标 + 康复师姓名）/ 待审核（warning）/ 未绑定（引导申请） |
| 康复师档案卡 | 头像、姓名、执业机构、执业类别、资格证号（脱敏）、擅长方向 chips、简介 |
| 操作 | 「发消息」按钮（跳 /patient/messages 并选中该会话）、「申请更换」入口（确认弹窗 → 提交申请） |

### 4.4 康复计划 `/patient/plans`

| 区块 | 内容 |
| --- | --- |
| 计划概览卡 | 当前计划：目标、周期（开始-结束）、整体完成率进度条 |
| 阶段任务列表 | 按阶段分组任务卡：训练动作、频次、时长、注意事项；今日任务带「打卡」按钮（accent-500） |
| 打卡面板 | 打卡弹窗：完成情况（√ 已完成 / 跳过并说明）、疼痛评分（1-10 滑块）、备注文本 → 提交 |
| 历史计划 | 已完成计划折叠列表 |

空态：无计划时显示「康复师正在为您制定计划」等待卡。

### 4.5 消息 `/patient/messages`

| 区块 | 内容 |
| --- | --- |
| 会话列表（桌面左栏/移动顶部） | 与康复师的一对一会话，显示头像、最后消息、时间、未读数徽标 |
| 聊天窗口 | 气泡消息（本人右 primary-50 底、对方左 white 底），时间分隔线，输入框 + 发送按钮 |
| 消息输入 | 文本输入（预留图片按钮 disabled 显示「即将上线」） |

交互：发送后滚动到底部；收到新消息顶部 Toast + 列表未读数更新；消息中异常提醒卡片（若康复师发送含告警摘要）以特殊样式展示。

### 4.6 个人档案 `/patient/profile`

| 区块 | 内容 |
| --- | --- |
| 基本资料 | 姓名、性别、出生日期、联系电话（编辑表单） |
| 健康档案 | 既往病史、过敏史、出院小结（可查看/重新上传） |
| 紧急联系人 | 姓名、关系、电话（仅本人可见提示） |
| 账号 | 修改密码入口、退出登录（确认弹窗） |

编辑交互：进入编辑态（表单高亮），保存按钮激活，保存成功 Toast。

## 5. 康复师端页面

### 5.1 患者列表 `/therapist`

**目标**：工作台首页，管理名下患者。

| 区块 | 内容 |
| --- | --- |
| 统计条 | 4 个统计卡：在册患者数、今日待处理告警、计划执行中、本周新增上报 |
| 搜索筛选 | 搜索框（姓名/手机号）、状态筛选（全部/需关注/告警中）、按最新上报排序 |
| 患者列表 | 卡片或表格：头像+姓名、绑定时间、最近上报时间、健康状态点、告警徽标、快捷操作（查看详情） |
| 告警横幅 | 若有紧急告警患者，置顶 danger 横幅「3 名患者存在紧急指标」→ 点击筛选 |

空态：无患者时显示「暂无在册患者，等待管理员分配」引导。

### 5.2 患者详情 `/therapist/patients/[id]`

**目标**：单患者全量信息，Tab 结构。

| Tab | 内容 |
| --- | --- |
| 概览 | 基本信息卡 + 最近健康数据卡片 + 当前计划摘要 + 未处理告警 |
| 健康数据 | 同患者端：趋势图（7/30 天）+ 历史表格（分页）+ 异常点标注 |
| 康复计划 | 计划列表/当前计划详情 + 「新建计划 / 调整计划」按钮 |
| 告警 | 告警列表（时间倒序）：级别徽标、指标、触发时间、状态（未处理/已联系/已处理）、处理操作 |
| 档案 | 完整患者档案（既往病史、过敏史、出院小结；紧急联系人**隐藏**） |

头部：返回按钮 + 患者姓名 + 状态徽标 + 「发消息」按钮。

### 5.3 制定/编辑康复计划 `/therapist/patients/[id]/plan`

| 区块 | 内容 |
| --- | --- |
| 计划信息 | 目标（必填，多行）、周期（开始日期 + 持续周数）、说明 |
| 阶段任务编辑器 | 可添加多个阶段，每阶段含多任务；任务字段：动作名称、频次（如「每日 3 次」）、时长/数量、注意事项 |
| 调整历史 | 若编辑已有计划：底部折叠「调整历史」（时间、操作者、变更摘要） |
| 操作 | 保存草稿 / 发布计划（发布后患者可见并开始打卡） |

交互：发布确认弹窗；表单校验（至少 1 个任务）。

### 5.4 数据监测看板 `/therapist/dashboard`

**目标**：多患者并行监测。

| 区块 | 内容 |
| --- | --- |
| 告警总览 | 未处理告警列表（按级别排序，danger 置顶），每条含患者、指标、时间、处理按钮 |
| 风险患者 | 指标连续越界的患者卡列表（最近 7 天异常次数 + 最近一次异常） |
| 计划进度 | 各患者计划完成率横向条形图/列表 |
| 上报活跃度 | 近 7 天上报人次柱状图 |

### 5.5 消息 `/therapist/messages`

与患者端结构一致，会话列表为名下患者；支持从患者详情直接发起会话。

### 5.6 个人档案 `/therapist/profile`

| 区块 | 内容 |
| --- | --- |
| 执业信息 | 执业机构、执业类别、资格证书编号、资质材料（查看） |
| 专业信息 | 擅长方向、简介（编辑） |
| 审核状态 | 顶部状态徽标：已通过（success）/ 审核中（warning）/ 已驳回（danger + 驳回原因 + 重新提交） |
| 账号 | 修改密码、退出登录 |

## 6. 管理端页面

### 6.1 数据看板 `/admin`

| 区块 | 内容 |
| --- | --- |
| 平台指标 | 用户总数、患者数、康复师数、今日上报量、今日告警数 |
| 告警分布 | 近 7 天告警趋势图 + 按类型（血压/心率/体温/血氧）分布 |
| 待办审核 | 待审康复师数、待审对接申请数（快捷跳转入口卡） |
| 平台动态 | 最近审计日志摘要（登录/审核/绑定变更） |

### 6.2 康复师认证审核 `/admin/reviews/therapists`

| 区块 | 内容 |
| --- | --- |
| 筛选 Tab | 全部 / 待审核 / 已通过 / 已驳回 |
| 审核列表 | 表格：姓名、执业机构、提交时间、状态徽标、操作（查看/审核） |
| 审核详情抽屉/页 | 资质信息 + 证明材料预览 + 驳回原因输入框 + 通过/驳回按钮（确认弹窗） |

### 6.3 对接审核 `/admin/reviews/matchings`

| 区块 | 内容 |
| --- | --- |
| 筛选 Tab | 待审核绑定 / 待审核解绑 / 已生效 |
| 申请列表 | 表格：患者、康复师、申请类型、时间、状态、操作（查看详情/通过/驳回） |
| 详情 | 患者+康复师摘要卡、申请理由（若有）、通过/驳回操作 |

### 6.4 用户管理 `/admin/users`

- 表格：用户、角色、状态（正常/停用）、注册时间、操作（查看/停用/启用）。
- 停用确认弹窗（danger 按钮）；停用后该用户立即无法登录与访问。
- 搜索：姓名/手机号/角色筛选。

### 6.5 告警阈值配置 `/admin/thresholds`

| 区块 | 内容 |
| --- | --- |
| 阈值列表 | 每个指标一行：指标名、下限、上限、单位、启用开关 |
| 编辑 | 内联编辑或弹窗，校验下限 < 上限，保存成功 Toast + 审计日志记录 |

指标：收缩压（90–180）、舒张压（60–110）、心率（50–120）、体温（35.5–38.5）、SpO2（90–100 下限 90）。

### 6.6 审计日志 `/admin/audit`

- 表格：时间、操作者、操作类型（登录/审核/绑定/解绑/阈值修改/停用）、对象、IP、结果。
- 筛选：操作类型、时间范围、搜索。
- 分页 + 每页 20 条；只读。

## 7. 错误与异常页

### 7.1 `/404`

- 居中：大号 404 图形（可用 SVG 图标，中性色）、文案「页面不存在或已移除」、按钮「返回首页」（primary）。

### 7.2 `/403`

- 居中：锁图标、文案「您没有权限访问该页面」、按钮「返回我的工作台」（按角色跳转对应首页）。

### 7.3 `/500`

- 居中：警示图标、文案「服务开小差了，请稍后重试」、按钮「重试」+「返回首页」。

## 8. 路由与权限总表

| 路由 | 角色 | 说明 |
| --- | --- | --- |
| /login, /register, /forgot-password | 匿名 | 已登录访问跳转对应角色首页 |
| /onboarding/patient | patient（未建档） | 首次建档强制引导，未完成可再次进入 |
| /onboarding/therapist | therapist（未提交资质） | 资质提交；提交后只读 |
| /patient/** | patient | — |
| /therapist/** | therapist | 其中 /therapist/patients/[id] 需校验该患者属于当前康复师（资源归属） |
| /admin/** | admin | 全部管理操作写审计日志 |
| 其余 | 任意已登录 | 404 |
